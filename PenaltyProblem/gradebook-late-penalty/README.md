# gradebook-late-penalty

Calculates the final score for a student submission after applying the
late-submission penalty policy.

## Run

```bash
npm test
```

No dependencies — Node 18+ only.

## Layout

- `src/latePenalty.js` – penalty calculation
- `test/latePenalty.test.js` – unit tests
- `data/grade-412-sample.json` – sample data attached to GRADE-412 by Support
